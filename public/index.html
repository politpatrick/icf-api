ICF & ICD-10-GM MCP

MCP-Server zum Nachschlagen und Prüfen von ICF-Kategorien und ICD-10-GM-Diagnosen, deutsche Fassungen des BfArM.

Endpunkt

/mcp

Streamable HTTP, ohne Anmeldung, nur lesend. Die Seite selbst speichert nichts.

In Claude einbinden

  • claude.ai / Claude Desktop: Einstellungen → Konnektoren → Benutzerdefinierten Konnektor hinzufügen, obige URL eintragen.
  • Claude Code: claude mcp add --transport http icf-icd /mcp

Tools

  • ICF: icf_search, icf_get_code, icf_list_chapters, icf_get_related, icf_get_qualifiers, icf_interpret_coding
  • ICD-10-GM 2026: icd_search, icd_get_code, icd_list_chapters, icd_check_code
